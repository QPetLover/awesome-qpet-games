
# Contributing

Thanks for helping improve Awesome QPet Games.

## What To Contribute

- Missing QQ Pet resources
- Better source information
- File checksums or duplicate reports
- Covers, screenshots, and descriptions
- Runtime notes and compatibility test results
- Corrections to titles, categories, or credits

## Source Rules

- Include where the file came from when possible.
- For private QQ community sources, do not publish group numbers, QQ IDs, or private nicknames.
- If a contributor wants public credit, include only the name or link they approved.
- Mark unclear sources as `unknown` instead of guessing.

## Binary Files

Large packages should be stored with Git LFS. Small resource files may be committed directly.

## Metadata

Please update metadata together with new files:

- `metadata/resources.yml`
- `metadata/games.yml` when the resource is a game
- `metadata/downloads.yml` when the resource is a package/download
- `metadata/checksums.sha256`
