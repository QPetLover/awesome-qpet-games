
# Archive Policy

- Keep source information whenever possible.
- Use `unknown` instead of guessing unclear origins.
- Do not publish private QQ group numbers, QQ IDs, or private member names.
- Use ASCII paths for archived files; keep original names in metadata.
- Store checksums for every archived file.
- Store large packages with Git LFS.
- Keep CDN URLs as source or mirror records, not as the only archive.
