
# Large Files

Installers, DMG files, ZIP files, and RAR files can exceed GitHub's normal file size limit.

This repository tracks these formats with Git LFS:

- `*.zip`
- `*.rar`
- `*.exe`
- `*.dmg`
- `*.7z`

Small SWF, image, HTML, JavaScript, JSON, and Markdown files are committed directly unless they become too large.
